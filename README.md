# 📚 Il linguista disperato

A linguistics blog inspired by the Instagram page **Il linguista disperato**.

> 🤓 I study linguistics to understand it, then explain it to understand it better.
>
> 🧠 Follow along if you are also "afflicted" by linguistics.

This project turns that idea into an accessible space for exploring language, sharing linguistic insights, and making complex topics easier to understand.

## ✨ About the project

The blog is built with [Astro](https://astro.build/) and is designed to support clear, engaging articles about linguistics. The content is written for curious readers, students, and anyone fascinated by how language works.

## 🚀 Getting started

Install the dependencies:

```sh
npm install
```

Start the local development server:

```sh
npm run dev
```

The site will be available at `http://localhost:4321`.

## 🧞 Available commands

| Command | Description |
| :------ | :---------- |
| `npm run dev` | Start the development server. |
| `npm run build` | Build the production site. |
| `npm run preview` | Preview the production build locally. |
| `npm run astro` | Run Astro CLI commands. |
